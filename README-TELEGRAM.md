# استفاده از گروه تلگرام به‌عنوان دیتابیس پامیر روغن

این نسخه از بک‌اند به‌جای MongoDB، از یک **گروه تلگرام** برای ذخیره‌ی داده‌ها استفاده می‌کند:

- کل اطلاعات برنامه (نمایندگان، سفارش‌ها، پرداخت‌ها، ادمین‌ها و ...) به‌صورت یک فایل JSON در گروه ذخیره و هر بار که چیزی تغییر کند، همان فایل به‌روزرسانی می‌شود («فایل دیتابیس زنده»).
- علاوه بر آن، هر بار یک نماینده، سفارش یا تراکنش **جدید** ثبت شود، یک پیام خوانا و جدا هم در گروه فرستاده می‌شود تا بتوانید فعالیت‌ها را زنده در گروه دنبال کنید.
- هرکسی که لینک دعوت گروه را داشته باشد می‌تواند اطلاعات را (به‌صورت پیام‌های ثبت‌شده) ببیند، اما فقط سروری که Token بات را دارد می‌تواند در دیتابیس بنویسد یا آن را از طریق برنامه بخواند.

---

## مرحله ۱ — ساخت بات تلگرامی

1. در تلگرام، جستجو کنید: **@BotFather**
2. دستور `/newbot` را بفرستید
3. یک نام دلخواه برای بات انتخاب کنید (مثلاً: `Pamir Oil DB`)
4. یک یوزرنیم برای بات انتخاب کنید — باید به `bot` ختم شود (مثلاً: `pamir_oil_db_bot`)
5. BotFather یک پیام با یک **Token** به شما می‌دهد، چیزی شبیه این:
   ```
   123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
   این را جایی امن نگه دارید — **این را با کسی به‌جز خودتان در گروه عمومی/چت‌های دیگر شریک نکنید.** این Token عملاً کلید کامل دیتابیس شماست.

---

## مرحله ۲ — اضافه‌کردن بات به گروه

1. وارد همان گروه تلگرامی شوید (لینکی که فرستادید: `https://t.me/+JMwTgm2G62w1NjNl`)
2. از منوی گروه → **Add Members** → یوزرنیم بات را که ساختید جستجو و اضافه کنید
3. روی بات در لیست اعضا بزنید → **Promote to Admin** (ادمین کنید) و حداقل این دسترسی‌ها را فعال کنید:
   - ✅ ارسال پیام (Post Messages)
   - ✅ پین کردن پیام (Pin Messages)
   - (بقیه دسترسی‌ها لازم نیست)

---

## مرحله ۳ — پیدا کردن Chat ID گروه

1. بعد از اضافه‌کردن بات، یک پیام ساده (مثلاً «سلام») در گروه بفرستید
2. در مرورگر، این آدرس را باز کنید (به‌جای `<TOKEN>` توکن خودتان را بگذارید):
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
3. در متن خروجی دنبال بخشی شبیه این بگردید:
   ```json
   "chat": { "id": -1001234567890, "title": "نام گروه شما", "type": "supergroup" }
   ```
4. همان عدد (معمولاً منفی و طولانی، مثل `-1001234567890`) همان **Chat ID** شماست.

> اگر خروجی خالی بود: مطمئن شوید پیام را *بعد* از اضافه‌کردن بات فرستاده‌اید، و چند ثانیه صبر کرده و دوباره صفحه را رفرش کنید.

---

## مرحله ۴ — تنظیم فایل `.env`

فایل `.env.example` را کپی کرده و به `.env` تغییر نام دهید، سپس مقادیر زیر را پر کنید:

```
TELEGRAM_BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TELEGRAM_CHAT_ID=-1001234567890
APP_SECRET=یک-رشته-تصادفی-طولانی-دلخواه-بسازید
```

`APP_SECRET` همان کلیدی است که برنامه‌ی HTML شما هنگام ارسال/دریافت داده باید در هدر `x-app-secret` بفرستد (دقیقاً مثل نسخه‌ی قبلی MongoDB).

---

## مرحله ۵ — اجرا / دیپلوی

به‌صورت محلی:
```bash
npm install
npm start
```

برای دیپلوی روی Render.com (دقیقاً مثل پروژه‌ی «Pamir Market Bot» قبلی‌تان):
1. این پوشه را در یک ریپازیتوری گیت‌هاب قرار دهید
2. در Render یک **Web Service** جدید بسازید و ریپو را وصل کنید
3. Build Command: `npm install` — Start Command: `npm start`
4. متغیرهای محیطی بالا (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `APP_SECRET`) را در بخش Environment در Render وارد کنید
5. بعد از دیپلوی، آدرس سرور (مثل `https://pamir-oil-backend.onrender.com`) را در برنامه‌ی تک‌فایلی HTML به‌جای آدرس قبلی بگذارید — نیازی به تغییر دیگری در کد HTML نیست، چون آدرس API (`/api/state`) دقیقاً همان قبلی است.

---

## نکات مهم

- **حجم داده:** فایل تلگرام حداکثر ۵۰ مگابایت می‌تواند باشد که برای این نوع داده (متن JSON) بیش از کافی است.
- **همزمانی:** اگر چند نفر همزمان از چند دستگاه بنویسند، آخرین نوشته برنده است (مثل نسخه‌ی قبلی MongoDB) — تداخل پیچیده مدیریت نمی‌شود.
- **امنیت:** Token بات را فقط در `.env` سرور نگه دارید؛ هرگز آن را داخل کد HTML/جاوااسکریپت سمت کاربر قرار ندهید، چون هرکسی که آن را ببیند می‌تواند در دیتابیس بنویسد یا آن را پاک کند.
- **پشتیبان‌گیری:** چون هر تغییر یک فایل جدید جایگزین فایل قبلی در همان پیام می‌شود، اگر بخواهید یک نسخه‌ی قدیمی را نگه دارید، بهتر است هر از گاهی فایل `pamir-state.json` را از تلگرام دانلود و جایی جدا ذخیره کنید.
